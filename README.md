# The Hack - Automotive Customer Survey & Call Analytics Dashboard

منظومة متقدمة لتحليل استبيانات ومكالمات رضا عملاء مراكز صيانة السيارات مع دقة حسابية صارمة 100%.

## 🚀 المميزات الرئيسية
- **دقة رياضية صارمة (Strict Mathematical Precision)**:
  - **حجم العمل الكلي (Total Workload)**: إجمالي السجلات داخل الشيت.
  - **تم التواصل (Contacted)**: السجلات التي تحتوي على قيمة في حالة التواصل.
  - **قيد الانتظار (Pending)**: السجلات الفارغة أو الخالية (`لم يتم الاتصال / فارغ`).
  - **نسبة الاستجابة (Response Rate %)**: `(تم الرد ÷ تم التواصل) × 100`.
  - **معدل الرضا الفعلي (CSAT %)**: يُحسب **فقط وحصرياً من المكالمات المجابة**:
    $$\text{CSAT} = \frac{\text{راضى}}{\text{راضى} + \text{غير راضى}} \times 100$$
    (العملاء الذين لم يردوا أو لم يتم الاتصال بهم لا يؤثرون إطلاقاً على نسبة الرضا).

- **معالجة واستيراد ملفات الإكسيل (Excel Parser Engine)**:
  - يدعم استيراد وتصدير ملفات `.xlsx` و `.xls` مباشرة في المتصفح.
  - تعرّف ذكي على الأعمدة القياسية:
    - الفرع: `'الفرع'`
    - الخدمة / المنتج: `'المنتج'`
    - حالة التواصل: `'حالة التواصل (تم الرد / لم يتم الرد)'`
    - حالة العميل: `'حالة العميل'`
    - مسئول الاستبيان: `'مسئول الاستبيان'` (مرجان، حسين، سارة...)
    - الفني: `'الفني'`
    - البائع: `'البائع'`
    - ملاحظات وشكاوى العميل: `'ملاحظات'`
    - ملاحظات الفرع: `'ملاحظات الفرع'`
    - اسم العميل ورقم الهاتف: `'العميل'` & `'الهاتف'`

- **لوحة متابعة حالات عدم الرضا (Escalations Table)**:
  - جدول مخصص للشكاوى والعملاء غير الراضين.
  - اتصال هاتفي مباشر بنقرة واحدة `tel:` أو محادثة واتساب فورية جاهزة بنص الزيارة.
  - زر توثيق الإجراء المتخذ وتحديد "تمت المعالجة".

- **رسوم بيانية تفاعلية (Chart.js)**:
  - مخطط حلقي (Donut) لمخرجات الاتصال (تم الرد، لم يتم الرد، مغلق/غير متاح، ممتنع، قيد الانتظار).
  - مخطط شريطي أفقي (Horizontal Bar Chart) لمقارنة نسب رضا الفروع مع إبراز الفروع ذات الأداء المميز (≥ 85%) والحرجة.

- **التكامل السحابي مع Supabase**:
  - تخزين محلي (LocalStorage/IndexedDB) فوري يعمل دون أي إعداد.
  - إمكانية ربط مشروع Supabase بنقرة واحدة لمزامنة البيانات سحابياً بين كافة الأجهزة وفريق العمل.
  - مرفق كود `schema.sql` لإنشاء الجداول وسياسات الأمان RLS مباشرة.
